Hyper Text :> A text which contain a link is called hyper text. Hyper Link : A link which re-direct from one link to another link is called hyperlink.
Markup Language :> A language in which we uses tags.
Tags :> Keywords wrapped between angular brackets.
Types of tags :> 1. Paired Tag 2. Unpaired Tag
(i) Paired Tag :> Those tag which is having opening tag and closing tag is called Paired Tag.
ex:- h1, p, h2, h4, table, form etc....
(ii) Unpaired Tag :> Those tag which is having only opening tag is called Unpaired Tag.
ex:- br, hr, input etc....
Attributes :> * It provided extra information about the tags. * It is used in the form of key amd value pairs, which is written inside opening tag.
There are two types of attributes :>
1. Global Attributes :> Those attributes which can be used with all the html tags , or whose effect can be applicable for the complete html, is known as Global Attribute.
ex : lang, id ,class, style, etc...
2. Local/Element specific Attriputes :> Those attributes which is used only for a particular element, it is known as local or element Specific Attribute.
ex : src, href, alt, cells, etc...
Link :>
A link (hyperlink) is a clickable text or image that is used to navigate from one webpage or location to another.
Link States :>
Unvisited Link :> A link to a webpage you have never clicked yet. Browsers typically display this as blue and underlined.
Visited Link :> A link to a webpage you have already clicked in the past. Browsers typically display this as purple and underlined.
Active Link :> Browsers display active link as red and underlined.
